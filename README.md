# Week 1 - Lab Setup & SOC Foundations

## Overview
This respository contains my week 1 progress in the Cybberster Blue Team Internahip. The focus was on building a SOC lab environment using VMware and deploying the Wazuh SIEM for monitoring and alerting.

## Lab Environment
- Kali Linux (Attacker)
- Ubuntu Server (Wazuh SIEM)
- Windows 10 (Monitored Endpoint)

Key Activities
- Network Configuration (NAT + Host-only)
- Wazuh installation and configuration
- Agent Deployment (Kali & Windows)
- Alert generation and monitoring
- MITRE ATT&CK mapping

## Tools Used

- VMware Workstation
- Wazuh SIEM
